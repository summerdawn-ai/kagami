# Security Policy

If you discover a security issue in Kagami, please report it privately instead of opening a public issue.

## Reporting a Vulnerability

Please contact the maintainers through GitHub Security Advisories or another private channel made available by the Summerdawn.ai team. Include:

- a description of the issue
- affected versions or commit SHAs
- reproduction steps or a proof of concept
- any suggested mitigations or fixes

We will acknowledge the report, investigate it, and coordinate a fix and disclosure timeline as appropriate.
